# 春风十里送大奖 · 云端自动更新

这个仓库每天自动更新彩票推荐页和足球推荐页。

**你的电脑关机也照常更新** —— 因为运行在 GitHub 的服务器上。

---

## 网址

部署完成后：

```
https://你的用户名.github.io/仓库名/
```

手机可以直接打开，发微信也行。

---

## 自动更新时间

```
GitHub 服务器每天 UTC 18:00 运行
        = 北京时间 02:00
```

想立刻更新：到 **Actions** 页 → 左侧选「每日自动更新」→ 点 **Run workflow**。

---

## 更新什么

| 内容 | 说明 |
|---|---|
| 开奖号码 | 官方接口（福彩 + 体彩）|
| 历史开奖 | 最近 60 期，用于统计热号冷号 |
| 足球赛事 | 未开赛 / 进行中 / 已完场 + 实时比分 |
| 竞彩赔率 | 欧赔 / 亚盘 / 大小球 |
| 奖级奖金 | 官方公布的单注奖金 |
| 推荐号码 | **每天凌晨 2:00 自动重摇全部 8 个彩种**（本地 + 云端都会跑）|
| 热力图 | 开奖日 18:00 出图、开奖时刻自动撤下（双色球 21:15 / 大乐透 20:30）|
| 已完场 | 比赛打完后自动归档到 `jc-history.js`，不会从列表消失 |

---

## 推荐号码怎么来的

- 号码池：按近 30 期频率 + 余数筛选自动算
- 胜负平：由博彩公司赔率反推概率（市场共识换算）
- 每期固定，开奖后自动归档，保留最近 30 期

**想换一套号码**：在本地程序点「一键摇号」（或跑 `roll-and-export.mjs`），
它会立刻把新号码写成 `saved-tickets.js` 和 `cloud/out/tickets.json`，
再由 `cloud/sync-cloud.mjs` 一起同步到这个仓库。

## 号码多久生效（准实时）

分享页（`index.html`）**不依赖重新构建页面**就能换号码：

1. 页面打开时先用内联的快照渲染 → 立刻有内容，离线也能看
2. 然后异步拉一次 `tickets.json`（每次都带时间戳绕过缓存）
3. 服务器那份的号码时间（`updated`）比页面新 → **就地重渲染**，
   顺便清掉 `localStorage` 里的旧号码，再重新做等比缩放
4. 第一次没拿到更新（云端还在部署）就隔 8s / 25s / 60s 各补拉一次
5. **页面一直开着时，每 90 秒自动再拉一次**（手机切回前台也会立刻拉）——
   所以云端更新后你**不用手动刷新**，页面自己会跟上

> 「最新开奖」区块也是同一条链路：`tickets.json` 里带了 `draws` 字段，
> 页面拿到新数据后会**重新渲染这块**（服务端和客户端共用同一个
> `latest-draws.js` 的 `latestDrawsHtml()`，避免两边写法漂移）。
> 也就是说**推荐图 + 最新开奖会一起更新**。

时间线（本地摇号 → 手机看到新号码）：

| 步骤 | 耗时 |
|---|---|
| 本机摇号 + 生成网页 + 写 `cloud/out/tickets.json` | 约 10 秒 |
| `sync-cloud.mjs` 上传（**只传变化的文件 + 8 个并发**）| 实测 **8-31 秒**（改之前 83-85 秒）|
| 云端构建（快速模式：不抓数据，只重新渲染） | 本机实测 0.4 秒；云端约 30-80 秒（含 Actions 排队 + Pages 部署） |

> 同步脚本只传「内容真的变了」的文件：先一次请求取回云端所有文件的
> blob 指纹，和本地算出来的比对，一样就跳过（日常同步 47 个文件里通常
> 只有 5-11 个需要上传）。
> 页面上的准实时机制让**已经在看的页面**也会自己跟上，
> 但 GitHub Pages 的部署延迟下限在 30 秒左右，这是平台限制。

`cloud-build.mjs` 的快速模式：`CLOUD_QUICK=1` 或 `sync-stamp.json`
小于 12 小时 → 跳过 `build-draws/history/football/jc/prizes`
这些慢抓取，只用同步过来的数据重新渲染。
**但热力图（`runHeatmapStep`，开奖日 18:00 抓当日晒票）不受这个开关影响**，
它由 `CLOUD_HEATMAP` / `HEATMAP_SLOT` 单独控制。

## 每天什么时候跑（北京时间）

| 时间 | 本地（电脑开着）| 云端（电脑关着也跑）|
|---|---|---|
| **02:00** | 全量：抓全部数据 + **强制重摇 8 彩种** + 生成页面 + 同步 | `full` 班次，同上 |
| 每 2 小时整点<br>00/02/04/…/22 | 抓足球 + 竞彩 → 出页面 → 同步 | 抓足球（云端能抓的才抓）|
| **18:00** | — | `heatmap-only`：出热力图 |
| **21:00** | — | `heatmap-off`：撤下热力图 |
| **21:40** | — | `draw-update` 班次 |
| **21:45** | **抓最新开奖结果 → 出页面 → 同步**（`update-draws.cmd`）| — |

> ⚠️ **云端抓不到中国的彩票官方接口**（福彩 403 / 体彩 567，GitHub 服务器在美国）。
> 所以「开奖号码」的更新**主要靠本机同步过去**：本机在 02:00 和 21:45 各同步一次。
> 电脑长时间关机时，云端仍能摇号、发页面，但开奖号码会停在最后一次同步的值。

```

cloud/cloud-build.mjs                云端构建主脚本
cloud/scripts/                       全部算法与渲染模块
  ├── games.js / stats.js / templates.js / render.js
  ├── build-draws.mjs / build-football.mjs / build-prizes.mjs
  ├── export-static.mjs / export-football.mjs
  └── saved-tickets.js               推荐号码存档
```
