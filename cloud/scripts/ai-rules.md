## ⚠️ 模板硬性条件（用户明确要求，不许改）

### 数字彩页脚（排列3 / 福彩3D，排列5 同理）
- **和值** → 推荐 **3 个数**（不是 `3~22` 这种区间）
- **和尾** → 推荐 **3 个数**（不是 `0~9` 这种区间）
- **对子号** → 推荐 **2 个数**（不是「对子号」三个字）
- 实现：`stats.js` 的 `digitFooterTop(areas, 'sum'|'tail'|'pair', N)`
  —— 从近 30 期真实开奖统计出现次数，取最热的 N 个

### 号码显示格式
- **数字彩里的 0 写成单个 `0`，不写 `00`**（0 是一位数）
- 其它个位数仍然补零（`1` → `01`、`4` → `04`）
- 实现：`stats.js` 的 `pad2 = (n) => (Number(n) === 0 ? '0' : String(n).padStart(2, '0'))`

### 区间宽度
- **和值区间不超过 20**（不要 71~141 这种太散的）
- **跨度区间不超过 15**
- 实现：`stats.js` 的 `compactRange(sorted, maxWidth, hardMax)`
  —— 传了 `hardMax` 就以中位数为中心压到该宽度

### 各彩种字段个数
| 彩种 | 字段 | 个数 |
|---|---|---|
| 双色球 | 蓝球推荐 | **6** |
| 排列5 | 万位 / 千位 / 百位 / 十位 / 个位 | 各 **3** |
| 排列3 / 福彩3D | 百位 / 十位 / 个位 | 各 **3** |

> 注意：`ticket-store.js` 里曾**硬编码**了个数（ssq 蓝球 1 个、dlt 后区 2 个…），
> 导致模板里写 `count` 不生效。现在改成「**模板写了就用模板的**，
> 没写才回落到默认值」—— 以后改个数只需要改 `templates.js`。

### 排列5 与排列3 的联动
- **排列5 的前三位必须和排列3 的三个位置完全一样**
  （排列5 万位 = 排列3 百位、千位 = 十位、百位 = 个位）

### 热号冷号
- **热号 = 从号码池内取**（≤6 个）
- **冷号 = 从号码池外取**（≤6 个）

### 热号排行显示

**任何两条互相矛盾 = 不合格，必须重算。**

## 六、三个特殊图的算法

### 九宫图（洛书）
基准洛书（只读）：`[[4,9,2],[3,5,7],[8,1,6]]`
1. 上期每个号码求数根（`getNumberRoot`，各位相加直到 <10）
2. 统计各宫出现次数 → **出现最多的宫 = offset**
3. 整个矩阵 +offset 平移（超 9 减 9）
4. 每期不同

### 九转连环图
`createJiuZhuan(上期号码, 'ssq'|'dlt')`
- 中心：双色球 **17** / 大乐透 **18**
- **4 个同心圆环 × 8 条米字轴 = 32 个交点**
  - 轴角度：0° / 45° / 90° / 135° / 180° / 225° / 270° / 315°
- 上期开奖号码**依次填进前 N 个空位**并标 `isHit: true`（双色球 6 个 / 大乐透 5 个）
- 其余交点保持空（`num: null`）
- **每期不同**

### 绕胆图（固定版式，不许改位置）
```
拖 拖 金 拖
拖 蓝 蓝 银
银 蓝 蓝 金
金 拖 拖 银
```
- 数量固定：**金 3 · 银 3 · 拖 6 · 蓝 4**
- **蓝球必须占中间 4 格**（位置 5/6/9/10，0 起算）
- 蓝球**不能和蓝球推荐重复**

### 五行阴阳
尾数 → 五行 + 阴阳：
```
0 阴土  5 阳土
1 阳水  6 阴水
2 阴火  7 阳火
3 阳木  8 阴木
4 阴金  9 阳金
```
